# 🌐 Quiz para Programadores

## 📖 Sobre o projeto

Este foi meu primeiro projeto desenvolvido utilizando **HTML**, criado para colocar em prática os conceitos aprendidos durante meus estudos de desenvolvimento web.

O projeto utiliza diferentes elementos HTML, como formulários, tabelas, listas, imagens, links e conteúdos expansíveis.

---

## 🎯 Objetivo

O objetivo do projeto foi praticar a **estruturação de páginas HTML** e entender como diferentes elementos podem ser utilizados juntos para criar uma página web organizada e funcional.

---

## 📚 O que aprendi

Durante o desenvolvimento, aprendi a utilizar:

- Estrutura básica do HTML;
- Títulos e parágrafos;
- `header`, `main`, `section` e `footer`;
- Formulários com `input`, `select`, `textarea`, `label`, `fieldset` e `legend`;
- Tabelas com `table`, `tr`, `th` e `td`;
- Listas com `ul`, `ol` e `li`;
- Imagens com `img`, `figure` e `figcaption`;
- Links com `a`;
- Conteúdo expansível com `details` e `summary`;
- Atributos como `id`, `name`, `value`, `type` e `placeholder`.

Este projeto também me ajudou a entender melhor a diferença entre **HTML (estrutura), CSS (aparência) e JavaScript (comportamento)**.
